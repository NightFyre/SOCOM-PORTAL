# SOCOM-PORTAL
Remaking the classic SOCOM experience inside Battlefield 2042 Portal

## Overview
This project recreates the tactical, team-based gameplay of the classic SOCOM series within Battlefield 2042's Portal mode. Experience the intense, strategic combat that made SOCOM legendary with modern graphics and mechanics.

**📚 [Complete Documentation Index](INDEX.md)** | **🚀 [Quick Start Guide](docs/QUICK_START.md)**

## Features
- Classic SOCOM game modes (Suppression, Extraction, Demolition)
- Tactical team-based gameplay
- Round-based elimination mechanics
- Authentic weapon restrictions and loadouts
- Strategic map control and objectives

## Game Modes

### Suppression
Classic team deathmatch elimination mode. Last team standing wins the round.

### Extraction
Attackers must rescue hostages while defenders protect them. Time-limited rounds with objective-based gameplay.

### Demolition
Plant and defuse gameplay. Attackers plant explosives on objectives while defenders attempt to defuse or eliminate all attackers.

## Setup Instructions

### Prerequisites
- Battlefield 2042 with Portal access
- Basic understanding of Portal's Rules Editor

### Creating the Experience
1. Open Battlefield 2042 Portal
2. Create New Experience
3. Import the configuration files from this repository
4. Configure the following settings:
   - Team setup (SEALs vs Terrorists)
   - Weapon restrictions
   - Map selection
   - Round and respawn rules

## Configuration Files
- `game-modes/` - Game mode rules and configurations
- `maps/` - Map-specific settings and layouts
- `weapons/` - Weapon loadout restrictions
- `settings/` - Team, round, and gameplay settings
