# Suppression Game Mode

## Overview
Suppression is the classic SOCOM elimination game mode. Two teams face off in round-based combat where the objective is simple: eliminate all enemy players to win the round.

## Rules
- Round-based gameplay
- No respawns during rounds
- First team to win predetermined number of rounds wins the match
- Last team with surviving players wins the round
- Round timer: 3-5 minutes (configurable)

## Team Setup
- **Team 1**: SEALs (Attackers)
  - 4-8 players
  - Spawn at designated starting location
  
- **Team 2**: Terrorists (Defenders)
  - 4-8 players
  - Spawn at designated starting location

## Win Conditions
- Eliminate all enemy players
- If time expires, team with most players alive wins
- If equal players, round is a draw

## Portal Configuration

### Basic Settings
```
Game Mode: Team Deathmatch (modified)
Respawn: Disabled
Round Limit: 11 (first to 6 wins)
Round Time: 180 seconds
```

### Advanced Rules
```
- Disable all vehicles
- Disable respawns
- Enable friendly fire (optional, for hardcore mode)
- Limit HUD elements
- Disable minimap (optional)
- Enable voice communications
```

## Recommended Maps
- Breakaway (modified for close quarters)
- Orbital (selected areas)
- Kaleidoscope (interior sections)
- Renewal (industrial areas)

## Scoring
- Round Win: 1 point per team
- Match Win: First to 6 rounds
- Individual Stats: Kills, Deaths, K/D Ratio

## Tips for Portal Setup
1. Use AI soldiers to fill teams if needed
2. Set spawn points strategically for balanced gameplay
3. Create out-of-bounds zones to limit play area
4. Use the Rules Editor to enforce elimination mechanics
5. Disable all kill streaks and call-ins
