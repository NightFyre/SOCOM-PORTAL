# Map Configurations

## Overview
Battlefield 2042 maps are large-scale battlefields designed for vehicles and massive player counts. For SOCOM gameplay, we need to modify these maps to create focused, tactical combat zones.

## Map Selection Criteria
- Close to medium range engagement distances
- Multiple cover positions and tactical routes
- Clear attack/defense delineation
- Limited vehicle access (or disabled entirely)
- Vertical gameplay opportunities
- Strategic chokepoints

## Recommended Map Configurations

### Breakaway (Antarctic Research Facility)

**Best Game Modes:** Suppression, Demolition

**Playable Area:** Research Station Interior + Exterior Platforms
- Focus on interior corridors and catwalks
- Use exterior platforms for strategic positioning
- Multiple entry points to buildings

**Spawn Points:**
- Attackers: North entrance
- Defenders: Central facility

**Objectives (Demolition):**
- Site A: Main Control Room
- Site B: Lower Generator Bay

**Boundary Setup:**
- Restrict to facility area only
- Block access to ice fields
- Limit to 200m x 200m combat zone

## General Map Modification Guidelines

### Boundary Setup
1. Use out-of-bounds zones to restrict play area
2. Create clear boundaries with environmental objects
3. Set reasonable out-of-bounds timers (5-7 seconds)
4. Test boundaries for exploitable positions

### Cover and Positioning
1. Ensure adequate cover throughout map
2. Create multiple tactical routes (minimum 3)
3. Balance open areas with close quarters
4. Include vertical positions (limited)

### Lighting and Visibility
1. Maintain clear sightlines
2. Avoid overly dark areas
3. Balance indoor/outdoor lighting
4. Consider time of day for visibility

### Objective Placement
1. Separate sites by 50-100m
2. Provide multiple approach angles
3. Create defendable positions
4. Balance attack/defense advantages

## Testing Checklist

- [ ] Spawn points are balanced (similar travel time)
- [ ] No direct spawn-to-spawn sightlines
- [ ] Multiple tactical routes available
- [ ] Objectives are accessible but defendable
- [ ] Cover is adequate throughout map
- [ ] Map boundaries are clear and fair
- [ ] No exploitable positions or glitches
- [ ] Round timer is appropriate for map size
- [ ] Extraction/objective points are logical
- [ ] Map plays well with selected game mode

## Tips for Map Setup

1. **Start Small:**
   - Begin with restricted areas
   - Gradually expand based on testing
   - Smaller is often better for SOCOM gameplay

2. **Test Thoroughly:**
   - Play test with full teams
   - Check all routes and positions
   - Time round completion
   - Gather feedback

3. **Balance is Key:**
   - Neither team should have clear advantage
   - Multiple strategies should be viable
   - Skill should determine outcomes

4. **Iterate:**
   - Adjust boundaries based on gameplay
   - Modify spawn points if needed
   - Update objective locations for balance
   - Refine based on community feedback
